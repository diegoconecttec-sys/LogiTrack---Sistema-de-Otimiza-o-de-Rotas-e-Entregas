# Comparativo: PaaS vs Kubernetes

| Critério             | PaaS (Railway/Heroku) | Kubernetes (EKS) |
| -------------------- | --------------------- | ---------------- |
| Complexidade         | Baixa                 | Alta             |
| Tempo de Implantação | Dias                  | Semanas          |
| Custo Inicial        | Baixo                 | Alto             |
| Escalabilidade       | Média                 | Alta             |
| Operação             | Simples               | Complexa         |
| Adequado para MVP    | Sim                   | Não              |

---

## Escolha Atual

PaaS Gerenciado.

### Justificativa

O projeto encontra-se em fase inicial, possui equipe reduzida e orçamento limitado.

---

## Evolução Planejada

Quando houver necessidade de escalabilidade granular e alta disponibilidade, a aplicação poderá migrar para Kubernetes.

---

## Conclusão

A escolha atual prioriza simplicidade e velocidade de entrega, mantendo caminho claro para evolução futura.
